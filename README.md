## 🎯 Project Overview

**EZ Budget** is a full-featured personal finance management app developed in **Kotlin** for Android, showcasing modern mobile development practices and clean architecture principles. Built as part of the PROG7313 (Open Source Android Programming) module at IIE's Varsity College.

## ✨ Key Features

- **🔐 User Authentication** - Secure login and registration with Firebase Authentication
- **📊 Transaction Management** - Log and categorize expenses and income with custom categories
- **📸 Receipt Capture** - Attach photo receipts to transactions for better record-keeping
- **🎯 Budget Goals** - Set and track personalized budgeting goals
- **📈 Visual Analytics** - Interactive spending graphs and reports
- **🏆 Gamification** - Ranking system with Bronze, Silver, Gold, and Diamond tiers to encourage financial discipline
- **☁️ Cloud Sync** - Firebase Firestore integration for real-time data synchronization
- **💾 Offline Support** - Local Room database ensures functionality without internet connectivity

## 🛠️ Tech Stack

- **Language:** Kotlin
- **Architecture:** MVVM (Model-View-ViewModel)
- **Database:** Room (local) + Firebase Firestore (cloud)
- **Authentication:** Firebase Auth
- **UI Framework:** Android XML Layouts with Material Design components
- **Build System:** Gradle (Kotlin DSL)
- **Image Handling:** Glide library for efficient image loading and caching

## 🚀 Getting Started

### Prerequisites

- **Android Studio** (latest stable version recommended)
- **JDK 19+**
- **16GB+ RAM** (recommended for smooth emulator performance)
- **Firebase account** (for cloud features)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Younous87/PROG7313_POE.git
   ```

2. **Open in Android Studio**
   - Open Android Studio and select "Open an Existing Project"
   - Navigate to the cloned directory

3. **Configure Firebase**
   - Add your `google-services.json` file to the `app/` directory
   - Update Firebase configuration if needed

4. **Build & Run**
   - Sync Gradle files
   - Run the application on an emulator or connected Android device
